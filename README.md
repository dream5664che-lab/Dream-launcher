# 💎 Dream Launcher

**Dream Launcher** — современный лаунчер Minecraft для Windows с интерфейсом в стиле **Liquid Glass / Fluent Design**. Проект сочетает минималистичный внешний вид, настройку игровых профилей и удобное управление запуском Minecraft.

### ✨ Возможности
- 🎮 Установка и запуск Vanilla Minecraft
- 🧩 Поддержка загрузчиков Fabric, Quilt и Forge
- 👤 Авторизация через Microsoft
- ⚙️ Настройка игровых профилей, Java, RAM и JVM-аргументов
- 📦 Просмотр установленных модов
- 🎨 Тёмный интерфейс с эффектами Liquid Glass
- 🗄️ Сохранение настроек и профилей в SQLite
- 📝 Журнал событий и отображение прогресса загрузки

### 🛠️ Технологии
- C# / .NET 9
- WPF
- CmlLib.Core
- SQLite
- MVVM

### 💻 Требования
- Windows 10/11 x64
- .NET 9
- Подключение к интернету для загрузки игровых файлов и авторизации

### 🚧 Статус проекта
Dream Launcher находится в разработке. NeoForge, установка модов из Modrinth/CurseForge и полноценная английская локализация пока не реализованы. Запуск Minecraft, авторизация Microsoft и установка загрузчиков требуют дополнительного тестирования на Windows.
